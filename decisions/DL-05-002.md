# DL-05-002: Derlemesiz ES modülleri + Node yerleşik `node:test` (sıfır bağımlılık)

- Tarih: 2026-07-26
- Faz: 5 — Mimari Tasarım
- Mod: AUTOPILOT
- Karar: Tarayıcı dosyaları `<script type="module" src="./src/app.js">` ile doğrudan yüklenir; bundler/transpiler/paket bağımlılığı YOKTUR. Testler Node'un yerleşik `node:test` + `node:assert` koşucusuyla `tests/board.test.js` içinde, saf `board.js` import edilerek yazılır (`package.json`: `"type":"module"`, `"test":"node --test"`).
- Değerlendirilen alternatifler: (1) Vite/bundler + Vitest (DX iyi, derleme adımı + onlarca bağımlılık); (2) jsdom ile DOM testleri; (3) tek dosya IIFE (modül yok, test edilemez).
- Gerekçe: NFR-3 açıkça "ek bağımlılık/derleme yok, saf HTML/CSS/JS" der; statik barındırma hedefiyle (Faz 1-2 fizibilite) birebir uyumludur. Yerleşik koşucu, kapı için gereken otomatik testleri (NFR-2, NFR-4) sıfır bağımlılıkla verir; DOM testi gerekmez çünkü kritik iddiaların tamamı saf çekirdektedir.
- Riskler: Node < 18 ortamında `node --test` yok — CI (Faz 12) Node 22 kullanır, `package.json.engines` bunu beyan eder. `file://` üzerinden ES modülü CORS'a takılabilir → README basit statik sunucu komutunu belgeler.
- Geri alınabilirlik: Yüksek (bundler sonradan eklenebilir; kaynak zaten standart ESM, kod değişmez).
- İnsan onayı: Otomatik
- Varsayım mı?: Hayır
