# DL-04-004: State modeli — tek düz (1D) hücre dizisi

- Tarih: 2026-07-26
- Faz: 4 — Çözüm Analizi
- Mod: AUTOPILOT
- Karar: Tahta tek bir düz dizide tutulur: `cells[r * cols + c] = { mine, adj, state }`; komşuluk tek bir `neighbors(i)` yardımcısıyla türetilir. 2D dizi ve Set-tabanlı modeller reddedildi.
- Değerlendirilen alternatifler: (G) 1D düz dizi [seçilen]; (H) 2D dizi `cells[r][c]`; (I) `mines`/`revealed`/`flags` Set üçlüsü.
- Gerekçe: Hedefli render (DL-04-003) "değişen indeks" listesiyle çalışır; 1D indeks, DOM çocuk indeksiyle birebir eşleşir (dönüşüm katmanı yok). Komşuluk mantığı tek fonksiyona indiğinden NFR-2'nin %100 doğruluk iddiası tek noktadan sınanır. Set modeli üç yapıyı senkron tutma yükü getirir ve 480 hücrede ölçülebilir bir kazanç sağlamaz.
- Riskler: Satır sonu taşması (sütun 0 ile son sütunun komşu sanılması) — `neighbors(i)` satır/sütun türetip sınır kontrolü yapar; köşe/kenar hücreleri için birim test zorunludur (Faz 9 kabul kriteri).
- Geri alınabilirlik: Yüksek (model `board.js` içinde kapsüllüdür; dış dünya yalnız indeks ve saf fonksiyon sözleşmesini görür).
- İnsan onayı: Otomatik
